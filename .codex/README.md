# Project-local design skills

This repository vendors the reviewed UI, UX, and animation skills requested for Tholi. They are available for project skill discovery in subsequent sessions and are read directly during the current implementation. Root `AGENTS.md` selects the relevant skills for each type of work.

`skills-manifest.json` records pinned upstream revisions, installation date, retained licenses, and every installed file's SHA-256. The Apple pull-request listing was reviewed on October 15, 2026 and had no open requests. The reviewed default-branch revision is installed. Skill assets are development references and are not bundled into the extension or website.

Upstream sources:

- https://github.com/dickwu/apple-design-skill
- https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- https://github.com/emilkowalski/skills
- https://github.com/ibelick/ui-skills

The accepted Tholi plan keeps Base UI, Iconoir, branded tokens, CSS transitions, and WAAPI. Those product decisions override generic framework recommendations in upstream skills. Audit skills govern read-only audits; implementation follows the accepted plan and construction skills.
