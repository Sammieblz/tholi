# Passive guidance and panel feedback

The guidance overlay is isolated in a closed shadow root, ignores pointer events and is hidden from the accessibility tree. The panel provides equivalent instruction text and verified progress in one polite, atomic status region. Its text changes with meaningful session/goal evidence; polling and geometry-only updates do not rewrite the announcement. Guide me is the primary live-navigation action and its accessible name matches its visible label. Goal entry receives focus after starting/resuming live navigation. Pause moves focus to Resume; Stop returns focus to the destination. Authored demo tasks retain Start. Decorative toolbar arrows are excluded from button names.

While guiding, one animation-frame loop reads the freshly bound target's rendered rectangle. Geometry changes, including CSS transforms and real browser zoom, redraw the halo without a decorative transition. Unchanged rectangles reuse the drawing. Hidden/disconnected targets clear it; Pause/Stop cancel the frame and listeners. The overlay never changes page focus, clicks, types or scrolls.

Instruction placement measures actual text dimensions and tries below, above and beside the target within viewport margins. A corner with the smallest overlap is the fallback when those placements cannot fit. The live coach can scroll a freshly bound offscreen control into view without clicking or focusing it; user input cancels pending scrolling. Direction indicators remain for targets outside the visible area. The panel provides equivalent text on small viewports. Consequential controls can receive a review highlight with an explanation; the user performs the action and fresh evidence verifies its result.

`tests/browser/extension/core/geometry.spec.ts` independently measures the closed-shadow overlay using CDP against the website control's rectangle. Cases exercise all four edges, CSS movement, scroll, resize, Chrome `tabs.setZoom` at 80%, 125% and 200%, reduced-motion preference, keyboard access to the underlying button, non-overlapping instruction placement and cleanup. `tests/browser/live/geometry.spec.ts` checks real Wikipedia language-control geometry at both declared layouts. Test-only CDP inspection does not expose the closed root to websites.

`tests/browser/extension/core/accessibility.spec.ts` uses keyboard activation for Start, goal submission, Pause/Resume/Stop, checks focus, a 300px panel, consequential warnings and guiding/waiting/awaiting-choice/unresolved/verified/paused/stopped live-region text. A mutation observer checks that periodic polling does not repeat the announcement. This is automated extension-page evidence; actual native Chrome side-panel behavior and screen-reader speech remain the hands-on checks in [chrome-handoff.md](../../guides/getting-started.md).
