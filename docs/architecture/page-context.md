# Page context and grounded intent

The collector now attaches a structural context to each actual control: ordered heading ancestry and named regions such as navigation, main, toolbar, form and dialog. It builds heading outlines within structural boundaries, then adds enclosing section headings and page headings. A footer does not inherit an unrelated article heading. References use the owning document or open shadow root. Structure uses generic HTML/ARIA; no website selector, URL route or article name enters this code.

Semantic matching uses the full heading/region context alongside control labels and descriptions, so repeated Edit controls can be distinguished by nested section qualifiers. Extra qualifiers in the nearest section reduce its rank: Edit Plot prefers the Plot section over Plot inspirations. This is a generic specificity rule. Unknown scope remains unknown. Structure changes alter signatures and revision numbers, invalidate pending guidance and update bounded browser-local memory. Sanitized structural metadata is retained with the control. Viewport placement is a transient categorical hint, omitted from persistent site knowledge. Current bounds and scroll geometry can accompany a model observation through the ephemeral perception sidecar; collected DOM editable contents and field values stay outside both projections and saved knowledge.

The optional model receives a retrieved view of the current observation. The existing generic ranker orders purpose evidence, requested terms and interface controls. Projection admits complete dependency bundles: a selected control retains its discovered openers, region parents and native frame parents, or the bundle is omitted. Ambiguous bare control IDs and their dependents are excluded rather than renamed. Both the local context and the versioned navigation observation use a maximum of 96 controls, 32 regions and 16 frames including the root. The 24,000-byte UTF-8 limit covers the whole serialized projection, including context, metadata, omissions and references. For a navigation observation, only PNG payload strings are excluded from this structural budget; image admission has separate limits in the [navigation contract](navigation-contracts.md). A byte limit does not guarantee that a browser model's token window will fit the request.

Discovery reuses the incremental control index and one per-snapshot geometry cache. The index retains its 5,000-control limit and cooperative eight-millisecond slices, and the page snapshot remains bounded to 600 controls. The raw perception sidecar has separate global bounds of 100 regions and 600 control metadata references before model projection. Generic HTML/ARIA dialogs, menus, landmarks, popovers and actual overflow scroll containers supply region ancestry; clipped overflow alone does not establish a scroll container. Region discovery traverses at most 64 DOM ancestors to find at most 16 region parents, leaving deeper ancestry explicitly unknown. The legacy heading and region summaries keep their existing format and ancestor bound.

`snapshotWithPerception()` pairs the page with its current `DiscoveryPerception`. Each geometry measurement has a fresh scan UUID, even when the semantic page revision is unchanged. Local evidence contains actual layout and VisualViewport metrics and device pixel ratio. The background binds the pinned native tab, window and document, verifies authorized frame ancestry, and adds the actual browser zoom to form `BrowserPerception`. Bounds remain in their owning frame's CSS coordinates; a visibility message does not establish a measured transform into the top frame. The sidecar travels beside `GET_PAGE`, outside `PageSnapshot`, `SessionView`, stored sessions and site memory. Foreground and continuing local-model requests consume the matching page/perception pair rather than geometry from a saved view.

Additional observations use a current region ID, scan UUID, page revision and native reference. An active discovery instance can prioritize that connected, permitted region through the same bounded scanner. Refinement cannot scroll, click, open a menu or acquire website access. Unknown, stale, detached or inaccessible regions cannot be replaced with a guessed region or route. Unmounted virtualized controls, closed shadow contents and saturated or incomplete scans remain unknown. Content-free projection diagnostics report observed discovery, composition and model omissions beside the payload, without estimating unseen controls or treating raw indexed candidates as eligible controls.

Each request clones a pristine Chrome Prompt API session, uses cancellation and a 30-second timeout, and destroys its clone. The shared context projection supplies the full sanitized user goal and up to eight verified step labels and kinds. The local model also receives the routing preference and task status, while raw objectives, field values and progress origins or paths stay outside the projection. Old raw pages and model responses do not acquire authority through accumulated chat history. The task carries context while current IDs and effects are revalidated. Enabling the base model retains the user-activated download flow; everything runs locally. See [task routing](../guides/journeys.md) and the separately versioned [multimodal navigation contracts](navigation-contracts.md).

Structured model output contains current control IDs, confidence and an intent: target purpose, requested context, page/section/any scope, and focus/reveal/choose/navigate/locate operation. The model may translate a paraphrase into the page's vocabulary. The planner independently finds an unambiguous eligible live route for that intent, requires the selected IDs to match that route, checks declared control kind against the proposed operation, and requires section/context qualifiers to come from the user's request. Scope constrains target eligibility while all discovered opening relationships remain available. Clear original semantic matches take precedence over conflicting proposals. Consequential and unknown-effect boundaries survive reinterpretation. Confidence is a heuristic, not a calibrated probability.

Accepted intent stays in the active goal plan. After a menu replaces its children or another target changes, replanning uses the same interpreted purpose against fresh observations and IDs; it does not reuse the model's old IDs. A new user goal cannot inherit a previous goal's interpretation. Observed results, not model text, determine verification. Opening a menu asks for a choice, focusing a search field does not establish a completed search, and navigation verifies the actual destination. Site memory still learns only visited structure and observed interactions, not model weights or imagined website routes.

Coverage includes nested heading qualifiers, changed structure and memory versions, late-control retrieval with opener retention, invalid/empty model fallback, invented IDs/context, dropped user qualifiers, tied controls and committing boundaries. Browser adapter tests use a deterministic model fake and replace a hidden menu child before proceeding to an independently checked destination. Live Wikipedia checks cover both unqualified article Edit and explicit Plot section Edit with actual halo geometry; they do not publish an edit. The default NLP path has separate real MiniLM tests. Real Gemini Nano paraphrase quality and native Chrome/model availability remain separate acceptance work. Authorized frames now support frame-local DOM discovery; Tesseract provides viewport text assistance with all frame pixels masked. Closed roots and broader visual understanding remain limitations. See [current architecture](navigation.md).

API reference: [Chrome Prompt API structured output and session management](https://developer.chrome.com/docs/ai/prompt-api).

With valid perception, the local model input stores each native frame once. A control's `frameId` selects that frame, and its unchanged `id` completes the native control reference. Its legacy region list can use ordered `structure.regionIds` when those retained ancestors reconstruct every sanitized role and name exactly and use fewer bytes. Otherwise the original region list is retained, including an empty list when the legacy ancestor cutoff found none. Heading evidence is unchanged. This lossless representation keeps the existing ranker, eligibility and admission limits; the separately versioned navigation observation retains its full native references.
