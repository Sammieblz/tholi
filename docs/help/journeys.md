# Choosing and changing a destination

Describe the result you want in ordinary English. A clear destination gives
Tholi a better starting point than a list of guessed clicks.

## Write a useful request

Try requests such as:

- "Find the language settings."
- "Change the text size to Large."
- "Show me where to create a new repository."

Include the setting, item or result you mean. If a website has several menus
called Settings, add context such as "Find my account settings."

Start with one task while learning Tholi. Longer requests and large web apps
can be harder to guide, and not every destination can be reached.

## Answer questions and make corrections

If Tholi asks which item or option you mean, choose the relevant answer or
clarify it in **Conversation**. Enter private details directly on the website
when appropriate. Do not paste passwords or verification codes into Tholi.

To change direction, explain the new result, such as "Use French instead."
If your new destination starts a separate task, an unfinished task may remain
available under **Resume previous task**. Use **Stop** when you want to cancel
the current guidance.

## Context and continuity

Tholi can keep your destination through supported menus, dialogs and page
changes. Complete website sign-in yourself. If the task moves to another
website or tab, review any access request and choose **Continue task here**
when offered.

Unrelated browsing can pause the task. Return to the intended website and
resume when you are ready. A retained destination does not guarantee that
Tholi can find the next step on every screen.

## Reuse a saved route

Tholi can remember reusable routes in this browser. Enable **Advanced controls**
in **Tholi settings** to see **Saved routes** when routes are available. During
guidance, choose an available route to use it again.

Saved routes are checked against the current website. **Learning route** means
a route has not established a completed result; **Reached before** describes
an earlier result, not a promise that it will work again. Saved routes can ask
for task details again and do not synchronize between browsers.

For session controls, see [Pausing and resuming](sessions.md). For removal
controls, see [Privacy and permissions](security.md).
