# Pausing and resuming

You decide when guidance continues. These controls affect your current task
and are separate from deleting saved routes or website memory.

## Pause and Resume

Choose **Pause** when you want to explore or read the website yourself. Tholi
keeps the destination but pauses guidance and checking. Choose **Resume** when
you are ready; Tholi checks the current page before guiding you again.

If the website is still loading or changing, give it a moment to settle before
resuming. Some questions or website-access requests need your answer first.

## Stop a task

Choose **Stop** to cancel current guidance. It does not undo actions you have
already taken on the website. Visible conversation history may remain until
you reset the session.

If a request contains several tasks, **Skip this task** moves past the current
one when available. Skipping does not mark that task as completed.

## Minimize without stopping

Closing the floating widget minimizes it to a small launcher. Your task, draft
and conversation remain, and authorized checking can continue. Expanded
highlights and automatic guidance scrolling stay hidden while minimized.

Select the launcher to return. If you removed the launcher, use the Tholi toolbar
icon. To pause or cancel checking, use **Pause** or **Stop** instead of minimizing.

## Return to an unfinished task

If **Resume previous task** is shown, select the destination you want to continue.
Tholi looks at the current website again before offering another instruction.
Removing an unfinished task does not delete learned website knowledge.

Private task continuity lasts for the browser session. Closing the browser ends
it. Saved routes are separate and may remain for later use.

## Reset the session

Open **Tholi settings**, enable **Advanced controls** if needed, and find
**Your data**. Choose **Reset current session** and review the confirmation.
This clears current and unfinished tasks, the draft and conversation.

It keeps saved routes and learned website knowledge. Use the separate controls
in [Privacy and permissions](security.md) when you want to remove those too.
