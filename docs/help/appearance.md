# Appearance

Tholi's extension and website have separate appearance controls.

## Extension contrast

The sidebar, floating widget and page guidance automatically contrast with
the website. Dark websites receive light guidance, and light websites receive
dark guidance. You do not need to change the Tholi website theme to use this.

Some image-heavy pages, videos or unusual website layouts can make the chosen
contrast less suitable. Try moving the widget or docking it to the sidebar.
If instructions remain difficult to read, [contact support](https://tholi.io/contact)
with the browser version and a description of the problem.

## Website Light and Dark

Use the **Light** or **Dark** control in the website header to switch appearance.
The website starts in Dark and does not automatically follow your device theme.

To remember your choice for later visits, allow appearance preferences in
**Cookie settings**. With **Essential only**, the switch still works for the
current page, but the preference is not saved. These choices do not configure
the installed extension.

Read the [cookie notice](https://tholi.io/cookies) for storage and website
measurement details.

## Reduce motion

Tholi respects your device or browser's reduced-motion preference. Enable that
preference in your system accessibility settings if you prefer less animation.
Necessary instructions and progress information remain available.

Website recordings have their own Pause and Resume controls. Pausing a recording
only affects that recording, not an installed extension task.

For widget placement and sizing, see [Using Tholi](using-tholi.md#widget-and-continuity).
