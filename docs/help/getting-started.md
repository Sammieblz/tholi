# Getting started

Tholi helps you find your next step on a website. Tell it what you want to do,
follow the highlighted control, and make the clicks yourself.

The current extension runs locally and needs no Tholi account. Use desktop
Chrome 140 or newer, or Firefox 153 or newer.

## Install Tholi

1. Open [Get Tholi](https://tholi.io/download).
2. Choose **Add to Chrome** or **Add to Firefox**.
3. Review the browser-store listing and permissions, then confirm installation
   in your browser. Opening the listing alone does not install Tholi.
4. Open your browser's **Extensions** menu and find Tholi. Pin it to the toolbar
   if you want to keep it within reach.

## Start your first task

1. Visit the website where you need help.
2. Select the Tholi toolbar icon. Allow access to that website if asked.
3. Enter a destination, such as "Find the language settings," then choose
   **Guide me**.
4. Read the instruction and use the highlighted control on the website.

Tholi checks your progress as the page changes. You still enter information,
sign in and decide whether to submit, purchase, delete or publish anything.
Some websites and complex tasks are not supported. Browser settings pages
cannot be guided.

## Try it before using a website

[Open the optional practice](https://tholi.io/onboarding) to explore a sample
task. Practice is separate from your installed extension. It cannot confirm
installation or change a real website.
