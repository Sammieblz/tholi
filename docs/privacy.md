# Local observation and memory

Observation starts only after Start. Pause and Stop remove DOM observers and guidance. Active live sessions follow same-origin page loads in their assigned tab; paused sessions require Resume. Opening the panel alone does not inject the content script.

Discovery reads control/heading labels, authored accessibility descriptions, roles, grouping, accessibility relationships, checked/expanded state and rendered geometry. It never reads input or textarea values, selected option values, user-editable text or full HTML. Sensitive fields and marked sensitive content are excluded. Text sanitization redacts emails, token-like strings, card digits and URLs. These heuristics cannot recognize every sensitive label on arbitrary websites.

Active sessions live in chrome.storage.session. Persistent site knowledge lives in extension-owned IndexedDB, separate from the website's storage. Stored records contain sanitized control metadata, sanitized paths without queries, non-security fingerprints, layout variants, version counters and inferred/observed transitions. Ephemeral document IDs/control IDs, the standalone complete-destination comparison key and geometry are excluded from persistent site records. Control signatures include hashed destination changes. Navigation destination verification uses an ephemeral hash of the target URL including its query; query values are not stored as text.

Knowledge is bounded to 50 sites, 100 pages, 30 templates, 5,000 controls and 400 transitions per site. Records expire after 90 days; expiry is enforced when storage is accessed. Forget this website and Clear all site memory stop current live observation before deleting data, preventing immediate recreation. Browser restart preserves knowledge; extension removal deletes extension-owned data. Goals remain in session records and are sanitized before matching or model use.

Optional AI runs in the extension side panel using Chrome's on-device Prompt API. Enabling it may download Chrome's model. Inference sends compact control metadata and the user's goal to that local model, with no remote inference endpoint. No website text is treated as an instruction. Diagnostic exports remain local and omit control labels, paths and field values.
