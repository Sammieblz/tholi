# Local observation and memory

Observation starts only after Start. Pause and Stop remove DOM observers and guidance. Active live sessions follow same-origin page loads in their assigned tab; paused sessions require Resume. Opening the panel alone does not inject the content script.

Discovery reads control/heading labels, authored accessibility descriptions, roles, grouping, accessibility relationships, checked/expanded state and rendered geometry. It never reads input or textarea values, selected option values, user-editable text or full HTML. Sensitive fields and marked sensitive content are excluded. Text sanitization redacts emails, token-like strings, card digits and URLs. These heuristics cannot recognize every sensitive label on arbitrary websites.

Active sessions live in chrome.storage.session. Persistent site knowledge lives in extension-owned IndexedDB, separate from the website's storage. Stored records contain sanitized control metadata, sanitized paths without queries, non-security fingerprints, layout variants, version counters and inferred/observed transitions. Ephemeral document IDs/control IDs, the standalone complete-destination comparison key and geometry are excluded from persistent site records. Control signatures include hashed destination changes. Navigation destination verification uses an ephemeral hash of the target URL including its query; query values are not stored as text.

Knowledge is bounded to 50 sites, 100 latest pages, 120 state snapshots (8,000 state controls), 30 templates, 5,000 latest-page controls and 400 transitions per site. There are at most 100 saved task routes, each with 30 verified interactions and 24 planned/predicted labels. Records expire after 90 days when accessed. Forget website removes its routes and routes that traversed it; Clear removes both stores. Observation stops before site deletion. Browser restart preserves knowledge; extension removal deletes extension-owned data. Sanitized goals and destination values now persist in saved task routes, with strategy, estimates and label/signature summaries. Saved routes can be forgotten individually.

Optional AI runs in the extension side panel using Chrome's on-device Prompt API. Enabling it may download Chrome's model. Input includes bounded sanitized controls, heading/region relationships, states, sanitized paths, categorical placement, the user's goal and up to eight verified task interactions. Native select option labels and selection flags are metadata; option values remain excluded. Every request clones a pristine system session and destroys its clone. Structured task state carries context; raw old pages and model guesses do not accumulate as conversation authority. No remote endpoint is used. Structural metadata persists with site controls; placement stays transient. Website text is untrusted data. Diagnostic exports remain local and omit control labels, paths, goals and field values.

The webNavigation permission supplies top-level redirect metadata for active authentication journeys. Events for unrelated tabs and subframes are ignored; accepted events retain only origin and URL hashes in session memory. No raw redirect query or authentication token is stored by Navigator. Per-host access is still required before observing the redirected page. Form metadata contains a hashed grouping key and an inferred login/register category from authored labels and input-type/autocomplete hints; private field controls and field contents remain excluded.
